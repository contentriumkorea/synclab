## SyncForge 1.1.2

- 앱 화면과 Mac 설치 프로그램의 표시 이름을 SyncForge로 변경했습니다.
- 기존 SyncLab 프로젝트 형식, 설치 경로, 실행 파일명과 업데이트 파일명을 유지합니다.
- 싱크 알고리즘과 Windows·Mac 기능은 1.1.1과 동일합니다.

## 설치

- macOS 15 이상: CPU에 맞는 `SyncLab-Install-macOS-arm64.dmg`(애플 실리콘) 또는 `SyncLab-Install-macOS-x64.dmg`(인텔)을 엽니다. 안의 **SyncLab 설치**를 실행하면 사용자 **응용 프로그램** 폴더에 설치됩니다.
- Mac 앱과 설치 프로그램에는 Apple 개발자 공증이 없습니다. 최초 실행 시 macOS가 차단할 수 있으며, 시스템 설정의 개인정보 보호 및 보안에서 해당 앱의 실행 허용이 필요할 수 있습니다.
- Windows: `SyncLab-Windows-x64.zip`을 모두 풀고 `SyncLab.exe`를 실행하거나, 기존 앱에서 **업데이트**를 누릅니다.

## 사용

프리미어에서 Final Cut Pro XML 내보내기 → SyncLab에서 XML 열기 → 자동 싱크 → XML 저장 → 프리미어에서 결과 XML 가져오기.

다른 컴퓨터에서 만든 XML은 원본 미디어 경로가 달라질 수 있습니다. 파일이 없다고 표시되면 **원본 위치 다시 지정**을 사용하세요. 그룹 사이 실제 시간 관계와 **확인 필요** 클립은 직접 확인해야 합니다.
